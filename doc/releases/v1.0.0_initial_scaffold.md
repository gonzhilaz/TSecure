# Release v1.0.0-alpha: Telkomsel Secure Mobile Security Scaffolding

## Highlights
- **Vigilance Modern Design System**: Implemented design tokens, Public Sans typography hierarchy, brand red `#ED0226`, `#0B132B` deep navy, and `#F4F6F9` slate surfaces.
- **Workflow & Kaspersky B2B Integration**: Built according to `Workflow.jpeg` with idempotent `Mobile ID` license guards, preventing multiple license billing handshakes.
- **Dynamic Security Scoring**: The device security gauge (e.g. 98%) is dynamically computed based on real-time protection, scan recency, Web Filter, Wi-Fi integrity, bootloader/Knox status, and storage encryption.
- **All Core Screens Implemented**:
  1. Splash Screen with automated session/hardware binding check.
  2. Masuk (Login) screen with Indonesian PDP Law (UU No. 27/2022) consent and instant authentication flow.
  3. Beranda (Dashboard) with dynamic circular arc gauge, quick-scan action, and 8 security shortcuts.
  4. Pemindaian (Full Scanner) with concentric radar scanning animation and real-time progress.
  5. Perangkat with telemetry bar charts and system audit items.
  6. Riwayat Aktivitas with monthly summary metrics and categorized timeline feeds.
  7. Profil with Halo Diamond tier, MyTelkomsel subscription validity period, and device license counter.
- **Engineering Standards Compliant**:
  - 100% of Dart files are modular and strictly under 400 lines.
  - Zero hardcoded secrets.
  - Tri-state completeness across all data-driven screens (Loading shimmer, Empty state, Error state with retry).
  - Mock data layer decoupled into `lib/data/mocks/`.
